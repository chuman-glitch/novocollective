# novocollective.org

Static landing page for Nōvo Collective. Plain HTML + CSS, no build step.

- `index.html` — the page
- `style.css` — all styles
- `img/` — web-sized photos (keep each under ~500 KB, 1600–2400px on the long edge)

Hosted on GitHub Pages with the custom domain in `CNAME`.

To add a new edition: add a `.ed` row in the project's editions list and drop 6–10 `<figure>` photos into its `.track` filmstrip.
